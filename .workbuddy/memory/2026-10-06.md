## v2.3.0：新增「谁是卧底」+ 服务器配置自愈

用户两条需求：①服务器配置缺失时自动生成默认配置并警告；②加入「谁是卧底」新玩法，并告知词库格式（词条由用户自己加）。

### 第 1 条：配置自愈
新增 `WerewolfGame/ConfigBootstrap.cs`，在 `WebApplication.CreateBuilder` **之前**调用：
- `appsettings.json` **缺失** → 写一份内置默认配置（`DefaultJson` 常量）+ 打印警告；
- **损坏**（非法 JSON）→ 先 `File.Move` 备份成 `appsettings.json.bad-yyyyMMdd-HHmmss` **再**重建，绝不静默丢弃用户手写的配置；
- 目录只读等写失败 → 不阻塞启动（回退内置缺省值），只提示。

**注意**：`DefaultJson` 与仓库里随源码发布的 `appsettings.json` 是**两份**，加配置节点时要一起改（已记入 MEMORY）。

### 第 2 条：谁是卧底（多游戏架构的第一次真实检验）
**结论：平台代码零改动**——只加文件 + 客户端 3 处注册点（工厂 case / DataTemplate / 控制台注册表），
`Program.cs` 一行没动（反射发现自动收录）。

新增文件：
- Share：`Games/UndercoverOps.cs`（ops + 阶段 + 身份常量）、`Games/UndercoverGameState.cs`（私有负载 + `UndercoverRules`）
- Server：`Games/Undercover/{UndercoverWordBank,UndercoverPlayer,UndercoverGameModule,UndercoverGameInstance}.cs`
- GUI：`ViewModels/Games/Undercover/UndercoverViewModel.cs`、`Views/Games/UndercoverPanel.xaml(.cs)`
- Console：`Games/UndercoverConsoleModule.cs`
- 测试：`UndercoverTests.cs`（词库/发牌/隔离）、`UndercoverProbe.cs`（`--undercover` 端到端）

玩法要点：
- 描述阶段**直接用聊天框**发言（不另造输入框，所有人描述留在同一条消息流里）；
  点「我说完了」，**全员就绪即提前进入投票**（不必等满时限）。
- 出局者**身份当场公开**，词到整局结束才揭晓；卧底数按人数 1/2/3 且保证平民 > 卧底。
- 词库：`words.undercover.txt`，每行 `平民词|卧底词[|分类]`，`#` 注释、空行忽略；
  缺失时 `EnsureSample` 自动生成示例并警告（与 appsettings 同一套自愈思路）。

   导致投票阶段要等满时限、探针提前超时。改为卧底本人弃票。

## v2.3.2：谁是卧底——隐藏本人阵营 + 大房间加入白板

用户两条：①玩家不该知道自己是卧底还是平民；②人数大到一定程度加入「白板」（没有词，只能靠推测）。
走 software-company 团队 SOP（快速模式：工程师寇豆码 → QA 严过关）。

### ① 隐藏本人阵营
- `UndercoverGameState` 新增 `HasWord` / `YourRoleKnown`；`YourRole` **局中恒为空**、只有 GameOver 后才下发。
- `BuildPayload`：`reveal = _dealt && (!_running || phase == GameOver)`。
  **坑（两处同源）**：`reveal` 原本用 `!_running`，未发牌时为 true，而 `_up` 里的人是 `SnapshotPlayers()`
  用默认角色 Civilian 补出来的 → **未开局就给所有人下发「平民」+ YourRoleKnown=true**；
  `DecoratePlayers` 的 `PlayerDto.Tag` 是同一个根因的另一半。两处都要加 `_dealt` 标志才一致
  （只修一处会出现「列表标签空白、身份徽标却写着平民」的自相矛盾）。
- 新增共享文案类 `UndercoverText`（在 `UndercoverOps.cs`），双端 + 服务端统一引用，客户端不再自己拼文案。

### ② 白板
- 纯函数 `UndercoverGameInstance.ComputeRoleCounts(n, rules) -> (Undercover, Blank)`，发牌与测试共用。
- 阈值进 `UndercoverRules`：`BlankMinPlayers=7`、`BlankTwoMinPlayers=10`（appsettings.json 与
  `ConfigBootstrap.DefaultJson` 两份同步）。
- **铁律 `平民 > 卧底 + 白板`**（`campCap=(n-1)/2`，先减白板再 clamp 卧底）。
  默认配额：3~5→(1,0)、6→(2,0)、7~8→(2,1)、9→(3,1)、10→(2,2)、11~12→(3,2)。
  10 人局卧底从 3 降到 2，否则 5 vs 5 开局即判卧底阵营胜（主理人裁定接受的取舍）。
- 白板**计入卧底阵营**参与胜负；出局即公开为「白板」；`RoleSummary` 公布白板数量（只是数量、不指向人）。
- **加固**：`MinPlayablePlayers=3` 兜底 + `Start()` 再验一次铁律，否则拒绝开局（防止有人把
  `Undercover:MinPlayers` 配成 1/2 导致开局瞬间判负）。

### 顺带修掉的一处锁序违规
`RunAsync` 原在 `lock(_sync)` 里调 `SnapshotPlayers()`（会取房间锁）→ 改为先取快照再进游戏锁。
QA 写了调用图级静态检查器交叉验证，全工程 0 可疑点。

### 验收（QA 判定 NoOne）
`--no-incremental` 全量重编 0/0；默认断言 **652 → 757 → 1195 → 1210**；`--ui` 64；
`--undercover` / 新增 `--ucblank <url> [人数]`（7 人局 1 白板、12 人局 2 白板真实对局）/ `--server` 24 /
`--rooms` 63 / `--newroles` / `--protocol` 44（需标准配置）/ `--lifecycle` 15（需专用配置）。
QA 独立审计新增 `UndercoverQaAudit.cs` + `UndercoverBlankProbe.cs`（整份 DTO 逐字段泄漏扫描、
假 IGameContext 抓真实私聊文案模板、ComputeRoleCounts 6 套阈值 × 3~12 人穷举）。

## v2.3.3 谁是卧底：词库改为「编译期内嵌」默认词库

需求：把代码目录下的 `words.undercover.txt` 作为程序默认词库，每次编译时自动打进程序。

### 实现要点
- `WerewolfGame/Werewolf.Server.csproj`：
  ```xml
  <None Remove="words.undercover.txt" />
  <EmbeddedResource Include="words.undercover.txt" LogicalName="words.undercover.txt" />
  <None Include="words.undercover.txt" CopyToOutputDirectory="PreserveNewest" />
  ```
  **必须给固定 `LogicalName`**，否则默认会变成 `Werewolf.Server.words.undercover.txt`（带根命名空间），读取时要跟着改。
- `UndercoverWordBank.cs`：新增 `EmbeddedResourceName` 常量 + `ReadEmbedded()`（`GetManifestResourceStream`）
  + `DefaultContent`；`EnsureSample()` 改为写**嵌入内容**（取不到才回退 `SampleContent`），警告文案区分来源；
  新增 `LoadOrDefault(path)`（文件优先，缺失**直接用内置、不写盘**，供只读工作目录兜底）；
  解析统一走 `ParseLines()`，杜绝两份解析逻辑漂移。
- `UndercoverGameInstance.LoadWordBank()` 改调 `LoadOrDefault`。
- 优先级铁律：**工作目录已有文件 > 内嵌默认 > 旧示例**。用户改过的词库永不被覆盖。

### 词库清理
原文件被运行时反复追加污染（重复的「300对」整块 + 3 条不雅词条：`尿|冰红茶`、`屎|香肠`、`床|棺材`）。
已重写：按 63 个分类归拢、去重 31 行 → **450 对**，UTF-8 无 BOM、LF，头注释说明格式。

  无空词/无同词、与源文件字节一致、`EnsureSample` 写出内嵌内容、用户改动不被覆盖、缺文件时 `LoadOrDefault` 兜底）；
  `--ui` 64 不变。
