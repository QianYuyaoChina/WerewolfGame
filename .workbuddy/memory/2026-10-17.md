## 1) 保留房间 Bug —— 根因已定位
- `Views/KeepRoomWindow.xaml.cs` 只有两个按钮 + Esc 会设置 `DialogResult`；**点标题栏 X / Alt+F4 时 `DialogResult` 仍为 `null`**。
- `MainWindow.xaml.cs:228-232` `AskKeepRoom()` 用 `dialog.ShowDialog() == true` 判定 → `null == true` → **false** → 按「不保留」走 → 服务端关房。
- 修法（已派 `software-engineer`）：新增 `Services/KeepRoomDecision.Resolve(bool?)` 纯函数（`null => true`）；`KeepRoomWindow` 覆盖 `OnClosing`，`DialogResult is null` 时置 `true`；`AskKeepRoom` 改用该纯函数；补 3 条纯函数断言 + 1 条源码级守护。
- **该语义必须被后续页面化重构继承**（已要求记入 TODO）。
